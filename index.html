章节导览（哈工大版 · 力学基础）

总览

按照哈工大版三力学的知识结构，从“什么是力”出发，逐步过渡到“力矩、力偶、等效力系与平衡”，再进入构件内力与应力分析。

推荐学习路径：力与力矩 → 力系简化和平衡 → 材料受力与应力 → 结构内力与变形 → 动力学与能量方法。

什么是力？（哈工大版·第一章）

理力

力是物体间相互作用的力学量，既可以改变物体的运动状态，也可以引起形状的变化。从工程角度看，力是我们用来描述和计算“结构和机器承受多大作用”的基本语言。

物理符合：想象你用手推墙——墙没有移动，但你和墙之间仍存在作用力，只是被墙的刚度“抵消”成看不见的微小变形。

什么是力矩？对点的力矩

结力

力矩刻画力使物体绕某一点（或某轴）产生转动趋势的大小，等于力的大小乘以力的作用线到该点的垂直距离。

物理符合：拧扳手时，同样大小的力，扳手越长越省力——力矩更大。哈工大教材中常以“门把手”解释：用手推门铰附近几乎推不动，本质是力臂太小。

力偶与力偶矩 · 等效力系

材力

两个大小相等、方向相反、作用线平行但不重合的力组成力偶，其合力为零，但对物体产生纯转动效应；力偶的作用可用“力偶矩”来表征。

物理符合：用扳手拧螺栓时，一手推一手拉就形成力偶——手上感觉不到整体平移，只感觉“扭”的效果，这就是纯转动。

受力图 · 如何“看清楚所有的力”

理力

受力图是把研究对象从周围环境中“剪切”出来，只保留它本身以及一切外力和约束反力的图，是写出平衡方程和内力方程的起点。

实际做题时，任何平衡分析、简支梁、刚架、桁架的计算都以一张清晰的受力图开始，哈工大教材反复强调“先画对图，再谈计算”。

平面力系简化 · 合力与合力矩

理力

任意平面力系都可以等效为某点上的一个合力和一个合力矩，这一过程称为平面力系的简化，是处理多力刚体问题的标准套路。

在平面刚体、多力门板、梁受多荷载问题中，先做力系简化可以大大降低平衡方程的复杂度，也是判断“是否可能三力平衡”的基础。

平衡方程 ΣFx=0, ΣFy=0, ΣM=0

理力 · 结力

平面刚体平衡时，沿两个互相垂直方向的合力为零、任意点的合力矩为零，这三个独立方程是求解支反力和外力的根本依据。

哈工大版中从门板、平面刚体到简支梁和刚架，所有静定问题都要回到这三条方程，理解它们比背公式更重要。

剪力与弯矩 · 截面内力的语言

结力

剪力和弯矩是描述梁截面内部受力状态的两个基本量，分别对应横向剪切作用和弯曲作用，是画内力图和进行强度校核的基础。

对简支梁、悬臂梁等模型，先利用平衡方程求支反力，再通过剪力与弯矩的定义沿梁“滑动截面”，即可得到完整的剪力图和弯矩图。

力臂 · 力矩的关键要素

理力

力臂是力的作用线到转动中心（或参考点）的垂直距离，用符号 d 表示。力矩的大小等于力的大小乘以力臂：M = F × d。

物理符合：门把手离铰链越远，开门越省力——这就是力臂的作用。在扳手模型中，力臂 d 的变化直接影响力矩 M 的大小，是理解“省力/费力”的关键。

力的四要素 · 完整描述一个力

理力

力的四要素包括：大小（F，单位 N 或 kN）、方向（用角度或单位向量表示）、作用点（力的作用位置）、作用线（力沿哪条直线作用）。

只有完整给出这四个要素，才能唯一确定一个力。在受力图中，力的表示必须包含这四个信息，缺一不可。

力偶矩 · 力偶的转动效应

理力

力偶矩是力偶对物体产生转动效应的度量，等于力偶中一个力的大小乘以两力作用线之间的垂直距离（力偶臂）。力偶矩的大小 M = F × d，方向垂直于力偶所在平面。

物理符合：用扳手拧螺栓时，两手之间的距离就是力偶臂d，力越大、距离越远，拧得越紧——这就是力偶矩的作用。力偶矩的一个重要性质是：它在平面内可以任意平移而不改变对刚体的作用效果。

力偶的平移不变性 · 等效替换的基石

理力

力偶在平面内可以任意平移而不改变对刚体的作用效果，这是力偶的一个重要性质。只要力偶矩的大小和方向不变，无论力偶作用在刚体的哪个位置，产生的转动效应都相同。

这个性质使得我们可以用"力偶矩"这个单一量来代表整个力偶，简化了力系的分析。在平面力系简化中，多个力偶可以合成为一个合力偶矩，这是处理复杂力系的关键步骤。

约束与约束反力 · 受力分析的起点

理力 · 结力

约束是限制物体运动的装置或条件。约束反力是约束对被约束物体施加的力，方向与约束限制的运动方向相反。常见的约束类型包括：固定铰支座、活动铰支座、固定端、光滑接触面等。

画受力图的第一步就是"去掉约束，用约束反力代替"。例如：固定铰支座提供两个反力分量（Fx, Fy），活动铰支座只提供垂直于支撑面的反力。这是所有静力学问题的基础。

静定与超静定 · 问题可解性的判断

结力

静定问题：未知约束反力的个数等于独立平衡方程的个数，可以用静力学平衡方程唯一求解。超静定问题：未知约束反力的个数多于独立平衡方程的个数，需要补充变形协调条件才能求解。

对于平面刚体，有3个独立平衡方程（ΣFx=0, ΣFy=0, ΣM=0），所以最多能求解3个未知量。简支梁有2个支座，提供2个未知反力，是静定的；连续梁有多个支座，是超静定的。

主矢与主矩 · 平面力系简化的结果

理力

平面力系向某点简化后，得到一个主矢FR（所有力的矢量和）和一个主矩MO（所有力对该点的力矩和）。主矢FR = ΣFi，主矩MO = ΣMi。这是平面力系简化的标准结果。

主矢的大小和方向与简化中心的选择无关，但主矩的大小与简化中心有关。当主矢和主矩都为零时，力系平衡；当主矢为零但主矩不为零时，力系等效为一个力偶。

力偶矢 · 力偶的向量表示

理力

力偶矢是表示力偶的向量，大小等于力偶矩的大小，方向垂直于力偶所在平面，指向由右手定则确定。力偶矢是自由向量，可以在空间内任意平移而不改变其物理意义。

力偶矢的引入使得力偶的合成和分解可以用向量运算来处理，大大简化了空间力系的分析。多个力偶可以合成为一个合力偶矢，合力偶矢等于各分力偶矢的矢量和。

三力平衡定理 · 静力学的重要定理

理力

如果刚体在三个力作用下处于平衡状态，且这三个力不平行，则这三个力必须共面且汇交于一点（或三力平行）。这是判断三力平衡问题的重要定理。

利用三力平衡定理，可以快速判断某些问题的可解性。例如：如果已知两个力的方向，第三个力的方向必须通过前两个力的交点。这在分析平面刚体、桁架等结构时非常有用。

等效力系 · 力系简化的理论基础

理力

如果两个力系对同一刚体产生相同的运动效应（平移和转动），则这两个力系互为等效力系。等效力系可以相互替换而不改变对刚体的作用效果。

力系简化的本质就是用一个简单的等效力系（主矢+主矩）来替代复杂的力系。例如：多个力可以简化为一个合力和一个合力矩；一个力可以等效地移动到作用线上的任意点。

力的平移定理 · 力可以等效移动

理力

作用在刚体上的力可以沿其作用线移动到任意点，而不改变对刚体的作用效果。如果要将力移动到作用线外的点，需要附加一个力偶，其力偶矩等于原力对新作用点的力矩。

力的平移定理是力系简化的基础。例如：将多个力向同一点简化时，每个力都可以平移到该点，同时附加相应的力偶矩，最终得到主矢和主矩。

力偶的合成与分解 · 多个力偶的处理

理力

多个力偶可以合成为一个合力偶，合力偶的力偶矩等于各分力偶矩的代数和（平面）或矢量和（空间）。力偶也可以分解为多个分力偶，满足力偶矩的合成关系。

在平面问题中，力偶矩是标量，合成时直接代数相加；在空间问题中，力偶矩是向量，合成时用向量加法。这是处理复杂力系中力偶部分的关键方法。

力对轴的矩 · 空间力学的力矩

理力

力对轴的矩是力使物体绕某轴转动的趋势大小，等于力在垂直于该轴的平面内的投影对该轴与平面交点的矩。力对轴的矩是标量，有正负号，表示转动的方向。

力对轴的矩与力对点的矩不同：对点的矩是向量，对轴的矩是标量。在空间力系平衡问题中，需要用到力对三个坐标轴的矩，这是空间平衡方程的基础。

力对点的矩的矢量表示 · 空间力矩

理力

力对点的矩是向量，用MO表示，大小等于力的大小乘以力臂，方向垂直于力与参考点构成的平面，指向由右手定则确定。MO = r × F，其中r是从参考点到力作用点的位置向量。

力对点的矩的矢量表示使得空间力矩的计算可以用向量叉积来处理，大大简化了空间力系的分析。力对坐标轴的矩等于力对该轴上任一点的矩在该轴上的投影。

空间力系的平衡方程 · 六个独立方程

理力

空间刚体平衡时，需要满足六个独立平衡方程：ΣFx = 0, ΣFy = 0, ΣFz = 0（三个力的平衡）和 ΣMx = 0, ΣMy = 0, ΣMz = 0（三个力矩的平衡）。

空间力系的平衡方程比平面力系多三个方程，这是因为空间刚体有六个自由度（三个平移和三个转动）。这六个方程是求解空间静力学问题的根本依据。

摩擦与摩擦力 · 静力学的重要概念

理力

摩擦力是接触面之间阻碍相对运动或相对运动趋势的力。静摩擦力Fs ≤ μs·N（μs为静摩擦系数，N为正压力），方向与相对运动趋势相反。动摩擦力Fk = μk·N（μk为动摩擦系数）。

摩擦力的存在使得很多实际问题需要考虑摩擦的影响。例如：斜面上的物体、楔块、皮带传动等。摩擦角是分析摩擦问题的重要工具，当主动力的方向在摩擦角内时，物体保持静止。

摩擦角与自锁 · 摩擦问题的几何分析

理力

摩擦角φ是最大静摩擦力与正压力的合力与正压力方向的夹角，tan(φ) = μs。当主动力的方向在摩擦角内时，无论主动力多大，物体都不会滑动，这种现象称为自锁。

摩擦角和自锁概念使得摩擦问题的分析更加直观。例如：斜面的自锁条件、楔块的自锁、螺旋的自锁等。自锁现象在工程中有重要应用，如千斤顶、夹具等。

滚动摩阻 · 滚动摩擦的概念

理力

滚动摩阻是物体滚动时受到的阻力，通常用阻力偶矩Mf来表示。Mf = δ·N，其中δ为滚动摩阻系数（单位：m），N为正压力。滚动摩阻通常远小于滑动摩擦，这就是为什么滚动比滑动省力。

滚动摩阻的产生是由于接触面的变形。例如：车轮在路面上滚动时，路面和轮胎都会发生微小变形，产生阻力偶。滚动摩阻系数δ的典型值在0.0005m到0.01m之间，远小于滑动摩擦系数。

桁架与节点法 · 结构力学的基础

结力

桁架是由直杆通过铰接连接而成的结构，各杆只受轴力（拉或压）。节点法是分析桁架内力的基本方法：取节点为研究对象，利用节点的平衡条件（ΣFx=0, ΣFy=0）求解各杆内力。

节点法的关键是：每个节点都是二力杆的交点，各杆的内力沿杆的轴线方向。通过逐个分析节点，可以求出所有杆的内力。这是分析桥梁、屋架等桁架结构的标准方法。

截面法 · 桁架分析的另一种方法

结力

截面法是分析桁架内力的另一种方法：假想用一个截面将桁架切开，取其中一部分为研究对象，利用该部分的平衡条件（ΣFx=0, ΣFy=0, ΣM=0）求解被切杆的内力。

截面法特别适用于只需求解少数几根杆的内力的情况。选择截面时，应使被切杆的数量不超过3根（平面问题），这样可以用3个平衡方程直接求解。截面法常与节点法配合使用。

刚架与刚架内力 · 结构力学的复杂结构

结力

刚架是由直杆通过刚接（或部分刚接）连接而成的结构，各杆可以承受轴力、剪力和弯矩。刚架内力的分析方法与梁类似：先求支反力，再用截面法求各截面的内力，最后画出内力图。

刚架比梁更复杂，因为刚架有多个杆件，各杆的内力需要分别计算。分析刚架时，通常先求支反力，然后分段（每段一个杆）用截面法求内力，注意在刚节点处内力要满足平衡条件。

应力与应变 · 材料力学的基础

材力

应力是单位面积上的内力，用σ（正应力）或τ（剪应力）表示，单位Pa或MPa。应变是单位长度的变形量，用ε（正应变）或γ（剪应变）表示，是无量纲量。应力与应变的关系反映了材料的力学性质。

应力是内力的"密度"，反映了材料内部的受力强度。应变是变形的"密度"，反映了材料的变形程度。在弹性范围内，应力与应变成正比（胡克定律），比例系数是弹性模量E或剪切模量G。

胡克定律 · 弹性材料的本构关系

材力

胡克定律描述了弹性材料中应力与应变的线性关系：σ = E·ε（正应力与正应变），τ = G·γ（剪应力与剪应变）。其中E是弹性模量（杨氏模量），G是剪切模量，都是材料的固有属性。

胡克定律只在弹性范围内成立，即应力不超过材料的比例极限。弹性模量E反映了材料抵抗拉伸（压缩）变形的能力，剪切模量G反映了材料抵抗剪切变形的能力。这是材料力学分析的基础。

强度条件与安全系数 · 材料力学的设计准则

材力

强度条件是保证构件安全工作的条件：σ ≤ [σ]（正应力强度条件），τ ≤ [τ]（剪应力强度条件）。其中[σ]和[τ]是许用应力，等于材料的极限应力除以安全系数n：[σ] = σu/n。

安全系数n考虑了材料性能的不确定性、载荷的波动性、计算方法的近似性等因素，通常取1.5到3.0之间。强度条件用于校核构件的安全性，或用于设计构件的尺寸。

扭转角与扭转刚度 · 圆轴扭转的变形

材力

扭转角φ是圆轴两端截面相对转动的角度，单位rad。扭转角与扭矩的关系：φ = (Mt·L)/(G·Ip)，其中L是轴长，G是剪切模量，Ip是极惯性矩。扭转刚度k = G·Ip/L，反映了轴抵抗扭转变形的能力。

扭转角公式与拉压杆的变形公式ΔL = (N·L)/(E·A)形式相似，都是"载荷×长度/(刚度×几何参数)"的形式。扭转刚度越大，相同扭矩下扭转角越小。这是分析传动轴、弹簧等构件的基础。

弯曲正应力 · 梁的弯曲应力

材力

弯曲正应力是梁弯曲时横截面上产生的正应力，用σ表示。弯曲正应力的计算公式：σ = (M·y)/Iz，其中M是弯矩，y是点到中性轴的距离，Iz是截面对中性轴的惯性矩。

弯曲正应力沿截面高度线性分布，中性轴处应力为零，上下边缘应力最大。最大弯曲正应力：σmax = M/Wz，其中Wz = Iz/ymax是抗弯截面系数。这是梁强度校核的基础。

弯曲剪应力 · 梁的剪切应力

材力

弯曲剪应力是梁弯曲时横截面上产生的剪应力，用τ表示。对于矩形截面，最大剪应力：τmax = (3V)/(2A) = (3V)/(2bh)，其中V是剪力，A是截面面积，b是宽度，h是高度。

弯曲剪应力沿截面高度呈抛物线分布，中性轴处最大，上下边缘为零。对于细长梁，弯曲正应力通常远大于弯曲剪应力，所以主要按正应力进行强度设计。但对于短粗梁，剪应力不可忽视。

挠度与转角 · 梁的变形

材力

挠度w是梁轴线上各点沿垂直于轴线方向的位移，转角θ是梁轴线的切线与水平线的夹角。挠度与转角的关系：θ = dw/dx。挠度与弯矩的关系：d²w/dx² = M/(E·Iz)，这是梁的挠曲线微分方程。

通过积分挠曲线微分方程，可以求出梁的挠度方程和转角方程。对于简单荷载情况，可以直接查表得到挠度和转角的公式。梁的刚度条件要求挠度不超过许用值，这是梁设计的重要指标。

组合变形 · 材料力学的复杂问题

材力

组合变形是指构件同时发生两种或多种基本变形（拉压、扭转、弯曲）的情况。常见的组合变形有：拉弯组合、压弯组合、弯扭组合等。分析组合变形时，先分别计算各基本变形产生的应力，然后叠加。

组合变形的应力叠加原理：总应力等于各基本变形产生的应力的代数和。例如：拉弯组合时，σ = σN + σM = N/A + M·y/Iz。强度条件需要考虑组合应力的影响，通常用第四强度理论或第三强度理论。

压杆稳定 · 材料力学的重要问题

材力

压杆稳定是指细长压杆在压力作用下可能发生失稳（突然弯曲）的现象。临界压力Fcr是压杆失稳时的最小压力，用欧拉公式计算：Fcr = π²EI/(μL)²，其中μ是长度系数，L是杆长。

压杆稳定与强度问题不同：强度问题关注应力是否超过材料的强度极限，稳定问题关注压力是否超过临界压力。细长压杆往往在应力远小于强度极限时就发生失稳，所以稳定问题不可忽视。

能量法 · 材料力学的能量分析方法

材力

能量法是利用能量原理（功能原理、虚功原理等）来分析结构变形和内力的一种方法。应变能U是结构在变形过程中储存的能量，对于线弹性材料：U = ∫(M²/(2EI))dx（弯曲），U = ∫(N²/(2EA))dx（拉压）。

能量法的优势在于可以处理复杂结构，特别是超静定结构。卡氏定理、单位荷载法、图乘法等都是能量法的具体应用。能量法在结构分析、优化设计等领域有广泛应用。

超静定结构 · 结构力学的重要问题

结力

超静定结构是未知约束反力的个数多于独立平衡方程个数的结构。求解超静定结构需要补充变形协调条件（几何条件），建立补充方程。超静定次数n = 未知量个数 - 独立平衡方程个数。

求解超静定结构的方法有：力法（以多余约束力为未知量）、位移法（以节点位移为未知量）、混合法等。超静定结构比静定结构更经济，因为可以利用多余约束来优化内力分布。

影响线 · 结构力学的移动荷载分析

结力

影响线是表示单位移动荷载在结构上移动时，某指定量值（反力、内力、位移等）随荷载位置变化的图形。影响线是分析移动荷载（如车辆、吊车等）对结构影响的重要工具。

绘制影响线的方法有：静力法（利用平衡条件）、机动法（利用虚位移原理）等。利用影响线可以确定移动荷载的最不利位置，求出某量值的最大值，这是桥梁、吊车梁等结构设计的基础。

运动学基础 · 理论力学的运动描述

理力

运动学是研究物体运动规律（位置、速度、加速度）的学科，不涉及力的作用。描述运动的基本量：位置矢量r、速度v = dr/dt、加速度a = dv/dt。运动方程r(t)描述了位置随时间的变化规律。

运动学是动力学的基础。通过运动方程，可以求出任意时刻的位置、速度和加速度。常见的运动形式有：直线运动、圆周运动、抛体运动、相对运动等。这是分析机械运动的基础。

点的速度与加速度 · 运动学的基本量

理力

速度v是位置矢量对时间的一阶导数：v = dr/dt，表示位置变化的快慢和方向。加速度a是速度对时间的一阶导数（或位置对时间的二阶导数）：a = dv/dt = d²r/dt²，表示速度变化的快慢和方向。

在自然坐标系中，加速度可以分解为切向加速度at（沿速度方向，改变速度大小）和法向加速度an（垂直于速度方向，改变速度方向）。对于圆周运动，an = v²/ρ，其中ρ是曲率半径。

法向加速度与切向加速度 · 加速度的分解

理力

在自然坐标系中，加速度a可以分解为切向加速度at和法向加速度an：a = at + an。切向加速度at = dv/dt（沿速度方向），改变速度的大小；法向加速度an = v²/ρ（指向曲率中心），改变速度的方向。

对于圆周运动，ρ = R（半径），an = v²/R = ω²R（向心加速度）。当速度大小不变时，at = 0，只有法向加速度；当速度方向不变时，an = 0，只有切向加速度。这是分析曲线运动的基础。

科氏加速度 · 相对运动的重要概念

理力

科氏加速度ac是动点在转动参考系中运动时产生的附加加速度，ac = 2ω × vr，其中ω是转动参考系的角速度，vr是动点相对于转动参考系的速度。科氏加速度的方向垂直于ω和vr所在的平面。

科氏加速度的产生是由于转动参考系的影响。在点的合成运动中，绝对加速度 = 牵连加速度 + 相对加速度 + 科氏加速度。科氏加速度在分析地球自转、旋转机械等问题时非常重要。

刚体的平面运动 · 刚体运动学的重要内容

理力

刚体的平面运动是指刚体内所有点都在平行于某一固定平面的平面内运动。平面运动可以分解为随基点的平移和绕基点的转动。平面运动刚体的角速度ω和角加速度α是标量，方向垂直于运动平面。

分析平面运动刚体上任意点的速度：v = v基 + v相对，其中v基是基点的速度，v相对是该点相对于基点的速度（大小等于ω×r，方向垂直于基点到该点的连线）。这是分析连杆机构的基础。

速度瞬心 · 平面运动分析的重要方法

理力

速度瞬心是平面运动刚体在某一瞬时速度为零的点。在该瞬时，刚体可以看作绕速度瞬心作瞬时转动。速度瞬心的位置可以通过已知两点速度的方向来确定：过两点分别作速度的垂线，交点即为速度瞬心。

利用速度瞬心可以简化平面运动的速度分析：刚体上任意点的速度大小等于角速度乘以该点到速度瞬心的距离，方向垂直于该点到速度瞬心的连线。速度瞬心法在分析连杆机构时非常有效。

动力学基本方程 · 动力学的核心

理力

动力学基本方程包括：质点的运动微分方程ma = F（牛顿第二定律）、动量定理dp/dt = F、动量矩定理dL/dt = M、动能定理dT = F·dr等。这些方程建立了力与运动之间的关系。

动力学方程是分析物体运动的基础。通过动力学方程，可以已知力求运动（正问题），或已知运动求力（逆问题）。对于刚体，还有刚体的运动微分方程：maC = F（质心运动定理），ICα = MC（转动方程）。

动量与冲量 · 动力学的重要概念

理力

动量p = mv是物体运动状态的量度，单位kg·m/s。冲量I = ∫Fdt是力对时间的累积效应，单位N·s。动量定理：Δp = I，即动量的变化等于冲量。对于系统，ΣΔpi = ΣIi（外力的冲量）。

动量定理特别适用于分析碰撞、冲击等问题。当系统不受外力或外力的冲量为零时，系统的总动量守恒：Σmivi = 常数。这是分析碰撞、爆炸等问题的基础。

动能与功 · 能量方法的基础

理力

动能T = (1/2)mv²是物体由于运动而具有的能量，单位J。功W = ∫F·dr是力对空间的累积效应，单位J。动能定理：ΔT = W，即动能的变化等于合力的功。对于系统，ΣΔTi = ΣWi（外力的功）。

动能定理是分析运动问题的重要工具，特别适用于已知力求运动的问题。当系统只有保守力做功时，机械能守恒：T + V = 常数，其中V是势能。这是分析振动、摆动等问题的基础。

机械能守恒 · 能量守恒的重要形式

理力

机械能守恒定律：当系统只有保守力（重力、弹性力等）做功时，系统的机械能（动能+势能）保持不变：T + V = 常数。势能V包括重力势能Vg = mgh和弹性势能Ve = (1/2)kx²。

机械能守恒是分析振动、摆动、抛体运动等问题的重要工具。利用机械能守恒，可以快速求出物体在任意位置的速度，而不需要求解微分方程。这是能量方法的优势。

动量矩与动量矩定理 · 转动动力学的基础

理力

动量矩L = r × p = r × mv是物体转动状态的量度，单位kg·m²/s。动量矩定理：dL/dt = M，即动量矩的变化率等于合外力矩。对于定轴转动刚体，L = Iω，其中I是转动惯量，ω是角速度。

动量矩定理是分析转动问题的重要工具。当系统不受外力矩或外力矩为零时，系统的总动量矩守恒：ΣLi = 常数。这是分析陀螺、旋转机械等问题的基础。

转动惯量 · 转动动力学的重要参数

理力

转动惯量I是刚体绕某轴转动时惯性的量度，I = ∫r²dm，单位kg·m²。转动惯量越大，改变角速度越困难。对于常见形状，有标准公式：圆盘I = (1/2)mr²，细杆I = (1/12)mL²（绕中心），I = (1/3)mL²（绕一端）。

转动惯量在转动动力学中的作用类似于质量在平动动力学中的作用。转动方程M = Iα（类似于F = ma）中，I是转动惯量，α是角加速度。平行轴定理I = IC + md²用于计算绕平行轴的转动惯量。

达朗贝尔原理 · 动静法的理论基础

理力

达朗贝尔原理：在运动的物体上，除了实际作用的外力F外，再假想地加上惯性力FI = -ma，则物体在形式上处于平衡状态：F + FI = 0。这样可以将动力学问题转化为静力学问题来处理。

达朗贝尔原理使得可以用静力学的方法（平衡方程）来求解动力学问题，这种方法称为动静法。惯性力是假想的力，不是实际存在的力，但在分析中可以当作真实力来处理。

虚位移原理 · 分析力学的基础

理力

虚位移是约束允许的、无限小的、假想的位移，用δr表示。虚位移原理：受理想约束的质点系处于平衡状态的充要条件是，所有主动力在任意虚位移上所做的虚功之和为零：ΣFi·δri = 0。

虚位移原理是分析力学的基础，可以用来求解静力学问题，特别是复杂约束系统。利用虚位移原理，可以避免求解约束反力，直接建立平衡条件。这是分析多约束系统的重要方法。

拉格朗日方程 · 分析力学的核心方程

理力

拉格朗日方程是分析力学的核心方程，用于描述约束系统的运动。对于保守系统，拉格朗日方程：d/dt(∂L/∂q̇i) - ∂L/∂qi = 0，其中L = T - V是拉格朗日函数（动能减势能），qi是广义坐标。

拉格朗日方程的优势在于可以用最少的坐标（广义坐标）来描述系统的运动，自动满足约束条件。这是分析复杂多体系统、机器人、航天器等问题的重要工具。

振动基础 · 动力学的重要应用

理力

振动是物体在平衡位置附近的往复运动。简谐振动是最基本的振动形式，运动方程：x = A·sin(ωt + φ)，其中A是振幅，ω是角频率，φ是初相位。固有频率ωn = √(k/m)，其中k是刚度系数，m是质量。

振动在工程中广泛存在，如机械振动、结构振动、电路振荡等。分析振动问题需要用到动力学方程、能量方法等。阻尼振动、强迫振动是振动的扩展形式，在实际问题中经常遇到。

单自由度振动 · 振动分析的基础

理力

单自由度振动系统只需要一个坐标就能完全描述其运动状态。无阻尼自由振动的运动方程：mẍ + kx = 0，解为x = A·sin(ωnt + φ)。有阻尼自由振动：mẍ + cẋ + kx = 0，其中c是阻尼系数。

单自由度振动是分析复杂振动系统的基础。阻尼比ζ = c/(2√(km))是判断振动类型的重要参数：ζ < 1为欠阻尼（振动），ζ = 1为临界阻尼，ζ > 1为过阻尼（非振动）。强迫振动的响应与激励频率有关。

多自由度振动 · 复杂振动系统

理力

多自由度振动系统需要多个坐标才能完全描述其运动状态。n自由度系统的运动方程：Mẍ + Cẋ + Kx = F(t)，其中M是质量矩阵，C是阻尼矩阵，K是刚度矩阵，x是位移向量，F是力向量。

多自由度系统有n个固有频率和n个主振型（模态）。主振型是系统的固有振动模式，每个主振型对应一个固有频率。系统的响应可以表示为各主振型的线性组合。这是分析复杂结构振动的基础。

碰撞问题 · 动力学的重要应用

理力

碰撞是两个物体在极短时间内发生相互作用的过程。碰撞过程中，由于碰撞力很大，可以忽略其他外力，系统的动量守恒：m1v1 + m2v2 = m1v1' + m2v2'。恢复系数e = (v2' - v1')/(v1 - v2)反映碰撞的弹性程度。

碰撞分为完全弹性碰撞（e = 1）、完全非弹性碰撞（e = 0）和非完全弹性碰撞（0 < e < 1）。碰撞问题的分析主要用到动量守恒定律和恢复系数的定义。这是分析冲击、爆炸等问题的基础。

刚体平面运动动力学 · 刚体动力学的重要内容

理力

刚体平面运动的动力学方程包括：质心运动定理maC = F（三个分量方程）和绕质心的转动方程ICα = MC。其中aC是质心加速度，F是合外力，IC是绕质心的转动惯量，α是角加速度，MC是合外力矩。

刚体平面运动有三个自由度（两个平动和一个转动），需要三个独立的动力学方程。分析刚体平面运动时，通常选择质心为基点，这样可以简化转动方程。这是分析连杆机构、车辆运动等问题的基础。

定轴转动动力学 · 转动动力学的基础

理力

定轴转动刚体的动力学方程：M = Iα，其中M是合外力矩，I是转动惯量，α是角加速度。这类似于平动的F = ma。定轴转动刚体的动能T = (1/2)Iω²，动量矩L = Iω。

定轴转动是最简单的转动形式，只需要一个坐标（转角）就能描述运动。分析定轴转动问题时，关键是计算转动惯量和合外力矩。这是分析飞轮、齿轮、电机等问题的基础。

质心运动定理 · 刚体动力学的基础

理力

质心运动定理：质点系的质心运动等同于一个质量等于质点系总质量、位于质心、受所有外力合力的质点的运动。数学表达式：maC = F，其中m是总质量，aC是质心加速度，F是合外力。

质心运动定理表明，无论质点系内部如何运动，质心的运动只取决于外力的合力。这大大简化了复杂系统的分析。质心坐标xC = Σmixi/m，yC = Σmiyi/m，zC = Σmizi/m。

惯性力与惯性力系 · 动静法的基础

理力

惯性力FI = -ma是假想的力，大小等于质量乘以加速度，方向与加速度相反。惯性力系是刚体上所有质点的惯性力组成的力系。对于平面运动刚体，惯性力系可以简化为一个惯性力FI = -maC（作用于质心）和一个惯性力偶MI = -ICα。

惯性力是达朗贝尔原理的核心概念。通过引入惯性力，可以将动力学问题转化为静力学问题。惯性力不是真实存在的力，但在分析中可以当作真实力来处理，这是动静法的理论基础。

功与功率 · 能量方法的基础

理力

功W = ∫F·dr是力对空间的累积效应，单位J。功率P = dW/dt = F·v是单位时间内做的功，单位W。对于定轴转动，功W = ∫Mdθ，功率P = Mω，其中M是力矩，ω是角速度。

功和功率是能量方法的基础。通过计算功，可以应用动能定理分析运动。功率反映了做功的快慢，在工程中用于选择电机、发动机等设备。效率η = 有用功率/输入功率是评价设备性能的重要指标。

势能 · 能量方法的重要概念

理力

势能V是物体由于位置而具有的能量。重力势能Vg = mgh（以某参考面为基准），弹性势能Ve = (1/2)kx²（以平衡位置为基准）。保守力做的功等于势能的减少：W = -ΔV。

势能是保守力场中物体的固有属性。当系统只有保守力做功时，机械能守恒：T + V = 常数。利用势能可以简化能量分析，避免计算复杂的路径积分。这是分析振动、摆动等问题的基础。

动能定理的应用 · 能量方法的重要应用

理力

动能定理ΔT = W是分析运动问题的重要工具。对于已知力求运动的问题，可以先计算各力做的功，然后应用动能定理求出速度。对于已知运动求力的问题，可以先计算动能变化，然后求出功，进而求出力。

动能定理的优势在于可以避免求解微分方程，直接建立速度与位置的关系。特别适用于分析复杂路径上的运动，如曲线运动、多体系统等。动能定理与机械能守恒结合使用，可以解决很多实际问题。

动量守恒定律 · 碰撞问题的基础

理力

动量守恒定律：当系统不受外力或外力的合力为零时，系统的总动量保持不变：Σmivi = 常数。这是分析碰撞、爆炸等问题的基础。对于两体碰撞，m1v1 + m2v2 = m1v1' + m2v2'。

动量守恒定律是物理学的基本定律之一，适用于所有相互作用过程。在碰撞问题中，由于碰撞时间极短，可以忽略其他外力，系统动量守恒。结合恢复系数，可以完全求解碰撞问题。

动量矩守恒定律 · 转动问题的基础

理力

动量矩守恒定律：当系统不受外力矩或外力矩的合力矩为零时，系统的总动量矩保持不变：ΣLi = 常数。对于定轴转动系统，I1ω1 = I2ω2。这是分析陀螺、旋转机械等问题的基础。

动量矩守恒定律在转动问题中的作用类似于动量守恒定律在平动问题中的作用。当转动惯量改变时（如花样滑冰运动员收臂），角速度会相应改变，以保持动量矩守恒。这是分析变质量转动系统的基础。

相对运动 · 运动学的重要概念

理力

相对运动是研究一个物体相对于另一个物体的运动。绝对运动 = 牵连运动 + 相对运动。绝对速度va = ve + vr，绝对加速度aa = ae + ar + ac，其中ve是牵连速度，vr是相对速度，ac是科氏加速度。

相对运动是分析复杂运动的重要方法。当动参考系作平动时，ac = 0；当动参考系作转动时，需要考虑科氏加速度。相对运动在分析地球自转、旋转机械、车辆运动等问题时非常重要。

牵连运动与牵连加速度 · 相对运动的重要概念

理力

牵连运动是动参考系相对于静参考系的运动。牵连速度ve是动点在动参考系上重合点的速度，牵连加速度ae是动点在动参考系上重合点的加速度。当动参考系作平动时，ae = aO（O是动参考系原点）。

牵连运动是相对运动分析的基础。理解牵连运动的关键是"动点在动参考系上重合点的运动"。当动参考系作转动时，牵连加速度包括切向加速度和法向加速度。这是分析复杂运动的基础。

点的合成运动 · 相对运动的综合应用

理力

点的合成运动是分析动点复杂运动的方法。速度合成定理：va = ve + vr，加速度合成定理：aa = ae + ar + ac。其中va是绝对速度，ve是牵连速度，vr是相对速度，ac是科氏加速度。

点的合成运动是分析复杂机构运动的基础。通过选择合适的动参考系，可以将复杂运动分解为简单的牵连运动和相对运动。这是分析曲柄滑块、凸轮机构等复杂机构的重要方法。

圆周运动 · 运动学的重要运动形式

理力

圆周运动是物体沿圆周路径的运动。角速度ω = dθ/dt，角加速度α = dω/dt。线速度v = ωR，切向加速度at = αR，法向加速度an = v²/R = ω²R。匀速圆周运动：ω = 常数，α = 0，at = 0，an = ω²R。

圆周运动是曲线运动的重要形式，在机械工程中广泛存在，如齿轮、飞轮、曲柄等。分析圆周运动时，通常用角量（θ, ω, α）描述，也可以用线量（s, v, a）描述，两者通过半径R联系。

抛体运动 · 运动学的重要运动形式

理力

抛体运动是物体在重力作用下的曲线运动。水平方向：x = v0x·t，vx = v0x（匀速运动）。竖直方向：y = v0y·t - (1/2)gt²，vy = v0y - gt（匀加速运动）。轨迹方程：y = x·tan(θ) - (gx²)/(2v0²cos²(θ))。

抛体运动是分析炮弹、投掷物等运动的基础。射程R = (v0²sin(2θ))/g，最大高度H = (v0²sin²(θ))/(2g)。抛体运动可以分解为水平方向的匀速运动和竖直方向的匀加速运动，这是分析复杂运动的基础。

直线运动 · 运动学的基础运动形式

理力

直线运动是物体沿直线路径的运动。匀速直线运动：x = x0 + v·t，v = 常数，a = 0。匀加速直线运动：x = x0 + v0·t + (1/2)at²，v = v0 + at，v² = v0² + 2a(x - x0)。

直线运动是最简单的运动形式，是分析复杂运动的基础。匀加速直线运动的三个基本公式是运动学的基础。当a = g（重力加速度）时，就是自由落体运动。这是分析所有运动问题的起点。

刚体的平动 · 刚体运动学的基础

理力

刚体的平动是指刚体内所有点的运动轨迹相同，任意时刻各点的速度、加速度都相同。平动刚体可以看作一个质点，其运动用质心的运动来描述。平动刚体的自由度：平面平动2个，空间平动3个。

刚体的平动是最简单的刚体运动形式。平动刚体的运动分析等同于质点的运动分析，所有点的运动状态完全相同。这是分析复杂刚体运动的基础，因为任何刚体运动都可以分解为平动和转动。

刚体的定轴转动 · 刚体运动学的重要形式

理力

刚体的定轴转动是指刚体绕固定轴转动，所有点都在垂直于转轴的平面内作圆周运动。定轴转动用转角θ描述，角速度ω = dθ/dt，角加速度α = dω/dt。刚体上任意点的速度v = ω×r，加速度a = α×r + ω×(ω×r)。

定轴转动是最简单的转动形式，只需要一个坐标（转角）就能描述运动。定轴转动刚体上各点的速度、加速度大小与到转轴的距离成正比，方向垂直于半径。这是分析齿轮、飞轮等转动部件的基础。

刚体的定点转动 · 空间转动的基础

理力

刚体的定点转动是指刚体绕固定点转动，需要三个欧拉角（ψ, θ, φ）来描述。角速度ω是向量，方向沿瞬时转轴，大小等于角速度的大小。刚体上任意点的速度v = ω×r，加速度a = α×r + ω×(ω×r)。

定点转动是空间转动的基础，陀螺、万向节等都是定点转动的例子。定点转动有三个自由度，需要用三个独立的角坐标描述。这是分析空间机构、航天器姿态控制等问题的基础。

角速度与角加速度 · 转动运动的基本量

理力

角速度ω是转角对时间的一阶导数：ω = dθ/dt，单位rad/s。角加速度α是角速度对时间的一阶导数（或转角对时间的二阶导数）：α = dω/dt = d²θ/dt²，单位rad/s²。对于定轴转动，ω和α是标量。

角速度和角加速度是描述转动运动的基本量，类似于线速度和线加速度在平动中的作用。匀角加速转动：θ = θ0 + ω0t + (1/2)αt²，ω = ω0 + αt，ω² = ω0² + 2α(θ - θ0)。这是分析转动问题的基础。

角量与线量的关系 · 转动与平动的联系

理力

角量与线量的关系：弧长s = Rθ，线速度v = Rω，切向加速度at = Rα，法向加速度an = Rω² = v²/R。其中R是点到转轴的距离。这些关系将转动运动与平动运动联系起来。

角量与线量的关系是分析转动问题的基础。通过半径R，可以将角量（θ, ω, α）转换为线量（s, v, a）。这使得可以用熟悉的平动公式来分析转动问题，大大简化了计算。

刚体的空间运动 · 刚体运动学的复杂形式

理力

刚体的空间运动是最一般的刚体运动形式，需要6个自由度描述（3个平动+3个转动）。空间运动可以分解为随质心的平动和绕质心的转动。质心运动用3个坐标描述，转动用3个欧拉角描述。

刚体的空间运动是分析复杂机构、航天器、机器人等的基础。空间运动的动力学方程包括质心运动定理（3个方程）和绕质心的转动方程（3个方程），共6个独立方程。这是分析空间机构的基础。

欧拉角 · 空间转动的描述方法

理力

欧拉角是描述刚体空间转动的三个独立角度（ψ, θ, φ）。进动角ψ：绕固定轴的转动；章动角θ：中间轴的倾斜角度；自转角φ：绕自身轴的转动。欧拉角可以唯一确定刚体的空间方位。

欧拉角是分析空间转动的基础，陀螺、万向节、航天器等都用欧拉角描述姿态。欧拉角的角速度可以通过欧拉角对时间的导数求得。这是分析空间机构、机器人运动学的基础。

平行轴定理 · 转动惯量的计算

理力

平行轴定理：刚体对某轴的转动惯量I等于对通过质心的平行轴的转动惯量IC加上质量m乘以两轴间距离d的平方：I = IC + md²。这大大简化了转动惯量的计算。

平行轴定理是计算转动惯量的重要工具。当已知对质心轴的转动惯量时，可以快速求出对任意平行轴的转动惯量。这是分析复杂形状刚体转动惯量的基础。

惯性积 · 转动惯量的扩展

理力

惯性积Ixy = ∫xydm，Ixz = ∫xzdm，Iyz = ∫yzdm是转动惯量的扩展概念，用于描述刚体对坐标轴的转动特性。惯性积可以是正值、负值或零。当坐标轴是主惯性轴时，惯性积为零。

惯性积在空间转动动力学中很重要，特别是在分析非对称刚体的转动时。惯性张量矩阵包含了转动惯量和惯性积，完整描述了刚体的转动特性。这是分析复杂空间转动的基础。

主惯性轴 · 转动惯量的重要概念

理力

主惯性轴是使惯性积为零的坐标轴。对于任意刚体，都存在三个相互垂直的主惯性轴，对应的转动惯量称为主转动惯量。当刚体绕主惯性轴转动时，角动量与角速度方向一致。

主惯性轴是分析空间转动的重要工具。对于对称刚体，对称轴就是主惯性轴。当刚体绕非主惯性轴转动时，会产生复杂的动力学行为，如陀螺效应。这是分析空间机构的基础。

陀螺效应 · 空间转动的重要现象

理力

陀螺效应是高速转动的刚体在受到外力矩作用时，产生垂直于外力矩方向的进动运动的现象。进动角速度Ω = M/(Iω)，其中M是外力矩，I是转动惯量，ω是自转角速度。

陀螺效应在工程中有重要应用，如陀螺仪、导航系统、自行车稳定性等。陀螺效应使得高速转动的物体具有稳定性，不易倾倒。这是分析空间转动、航天器姿态控制等问题的基础。

恢复系数 · 碰撞问题的重要参数

理力

恢复系数e = (v2' - v1')/(v1 - v2)是描述碰撞弹性程度的参数，取值范围0 ≤ e ≤ 1。e = 1为完全弹性碰撞（动能守恒），e = 0为完全非弹性碰撞（碰撞后一起运动），0 < e < 1为非完全弹性碰撞。

恢复系数是分析碰撞问题的重要参数。结合动量守恒定律，可以完全求解碰撞问题。恢复系数取决于碰撞物体的材料性质，可以通过实验测定。这是分析冲击、爆炸等问题的基础。

完全弹性碰撞 · 碰撞问题的特殊情况

理力

完全弹性碰撞（e = 1）是碰撞过程中动能守恒的碰撞。对于两球碰撞，动量守恒：m1v1 + m2v2 = m1v1' + m2v2'，动能守恒：(1/2)m1v1² + (1/2)m2v2² = (1/2)m1v1'² + (1/2)m2v2'²。

完全弹性碰撞是理想情况，实际碰撞中动能会有损失。但对于某些材料（如钢球），可以近似为完全弹性碰撞。完全弹性碰撞的求解需要同时满足动量守恒和动能守恒，可以完全确定碰撞后的速度。

完全非弹性碰撞 · 碰撞问题的另一种特殊情况

理力

完全非弹性碰撞（e = 0）是碰撞后两物体粘在一起运动的碰撞。碰撞后速度：v' = (m1v1 + m2v2)/(m1 + m2)。动能损失最大，损失的动能为：ΔT = (1/2)(m1m2/(m1+m2))(v1-v2)²。

完全非弹性碰撞在实际中常见，如子弹射入木块、汽车碰撞等。完全非弹性碰撞只满足动量守恒，不满足动能守恒。损失的动能转化为内能、变形能等。这是分析冲击、爆炸等问题的基础。

非完全弹性碰撞 · 碰撞问题的一般情况

理力

非完全弹性碰撞（0 < e < 1）是介于完全弹性碰撞和完全非弹性碰撞之间的碰撞。碰撞过程中动能不守恒，有动能损失。结合动量守恒和恢复系数，可以求解碰撞后的速度。

非完全弹性碰撞是最常见的情况，实际碰撞大多属于此类。恢复系数e的值取决于碰撞物体的材料性质，可以通过实验测定。非完全弹性碰撞的动能损失介于完全弹性碰撞和完全非弹性碰撞之间。

质心坐标 · 质点系分析的基础

理力

质心坐标是质点系质心的位置坐标。对于n个质点，质心坐标：xC = Σmixi/m，yC = Σmiyi/m，zC = Σmizi/m，其中m = Σmi是总质量。质心是质点系的质量中心，是分析质点系运动的重要参考点。

质心坐标是分析质点系运动的基础。质心运动定理表明，质点系的质心运动等同于一个质量等于总质量、位于质心、受所有外力合力的质点的运动。这大大简化了复杂系统的分析。

质点系的动量 · 质点系动力学的基础

理力

质点系的动量p = Σmivi是各质点动量的矢量和。质点系的动量等于总质量乘以质心速度：p = mvC，其中m是总质量，vC是质心速度。这是质点系动量的重要性质。

质点系的动量定理：dp/dt = F，其中F是合外力。当系统不受外力或外力的合力为零时，系统的总动量守恒：p = 常数。质点系的动量等于质心动量，这大大简化了动量分析。

质点系的动能 · 质点系能量分析的基础

理力

质点系的动能T = Σ(1/2)mivi²是各质点动能的总和。对于刚体，动能可以分解为随质心的平动动能和绕质心的转动动能：T = (1/2)mvC² + (1/2)ICω²，其中IC是绕质心的转动惯量。

质点系的动能定理：ΔT = W，其中W是外力的功。对于刚体，动能分解为平动动能和转动动能，这使得可以用熟悉的公式来分析复杂运动。这是分析多体系统、机构运动的基础。

质点系的动量矩 · 质点系转动分析的基础

理力

质点系的动量矩L = Σri×mivi是各质点动量矩的矢量和。对于刚体，动量矩可以分解为质心的动量矩和绕质心的动量矩：L = rC×mvC + LC，其中LC是绕质心的动量矩。

质点系的动量矩定理：dL/dt = M，其中M是合外力矩。当系统不受外力矩或外力矩的合力矩为零时，系统的总动量矩守恒：L = 常数。这是分析转动问题的基础。

保守力与非保守力 · 能量分析的基础

理力

保守力是做功与路径无关的力，如重力、弹性力、万有引力等。保守力做的功等于势能的减少：W = -ΔV。非保守力是做功与路径有关的力，如摩擦力、阻力等。非保守力做的功会转化为其他形式的能量。

保守力与非保守力的区分是能量分析的基础。当系统只有保守力做功时，机械能守恒；当有非保守力做功时，机械能不守恒，但总能量（包括内能等）仍然守恒。这是分析能量转换的基础。

功能原理 · 能量方法的核心

理力

功能原理：系统动能的增量等于所有外力做的功：ΔT = W。对于保守系统，ΔT = -ΔV，即Δ(T + V) = 0，机械能守恒。对于非保守系统，ΔT = W保守 + W非保守 = -ΔV + W非保守。

功能原理是能量方法的核心，是分析运动问题的重要工具。功能原理可以避免求解微分方程，直接建立速度与位置的关系。特别适用于分析复杂路径上的运动，如曲线运动、多体系统等。

虚功原理 · 分析力学的基础

理力

虚功原理：受理想约束的质点系处于平衡状态的充要条件是，所有主动力在任意虚位移上所做的虚功之和为零：ΣFi·δri = 0。虚位移是约束允许的、无限小的、假想的位移。

虚功原理是分析力学的基础，可以用来求解静力学问题，特别是复杂约束系统。利用虚功原理，可以避免求解约束反力，直接建立平衡条件。这是分析多约束系统的重要方法。

广义坐标 · 分析力学的重要概念

理力

广义坐标是能够唯一确定系统位形的独立坐标，用q1, q2, ..., qn表示。广义坐标的个数等于系统的自由度。广义坐标可以是长度、角度等任何物理量，不一定是笛卡尔坐标。

广义坐标是分析力学的重要概念，使得可以用最少的坐标来描述系统的运动。拉格朗日方程用广义坐标表示，自动满足约束条件。这是分析复杂多体系统、机器人、航天器等问题的重要工具。

广义力 · 分析力学的重要概念

理力

广义力Qk是与广义坐标qk对应的力，定义为：Qk = ΣFi·(∂ri/∂qk)，其中Fi是作用在第i个质点上的力，ri是第i个质点的位置矢量。广义力可以是力、力矩等任何物理量。

广义力是分析力学的重要概念，使得可以用统一的框架来处理不同类型的力。拉格朗日方程中的广义力项Qk，对于保守系统，Qk = -∂V/∂qk。这是分析复杂多体系统的基础。

拉格朗日函数 · 拉格朗日方程的基础

理力

拉格朗日函数L = T - V是动能T与势能V的差，是拉格朗日方程的核心。对于保守系统，拉格朗日方程：d/dt(∂L/∂q̇k) - ∂L/∂qk = 0，其中qk是广义坐标，q̇k是广义速度。

拉格朗日函数是分析力学的重要工具，使得可以用统一的框架来描述各种系统的运动。拉格朗日方程的优势在于可以用最少的坐标来描述系统的运动，自动满足约束条件。这是分析复杂多体系统的基础。

哈密顿函数 · 哈密顿力学的基础

理力

哈密顿函数H = Σpkq̇k - L = T + V是系统的总能量（动能+势能），其中pk = ∂L/∂q̇k是广义动量。哈密顿方程：q̇k = ∂H/∂pk，ṗk = -∂H/∂qk，这是分析力学的另一种表述形式。

哈密顿函数是哈密顿力学的基础，与拉格朗日力学等价但形式不同。哈密顿方程是一阶微分方程组，在某些情况下比拉格朗日方程更容易求解。这是分析复杂多体系统、量子力学等问题的重要工具。

广义动量 · 分析力学的重要概念

理力

广义动量pk = ∂L/∂q̇k是拉格朗日函数对广义速度的偏导数，是分析力学的重要概念。对于平动，广义动量就是普通动量；对于转动，广义动量就是角动量。广义动量与广义坐标构成相空间。

广义动量是分析力学的重要概念，使得可以用统一的框架来处理不同类型的动量。哈密顿方程用广义动量和广义坐标表示，这是分析复杂多体系统、量子力学等问题的重要工具。

约束与约束方程 · 分析力学的基础

理力

约束是限制系统运动的条件，用约束方程f(r1, r2, ..., t) = 0表示。完整约束是可以用约束方程表示的约束，非完整约束是不能用约束方程表示的约束。理想约束是约束反力不做功的约束。

约束是分析力学的基础，拉格朗日方程自动满足完整约束。通过选择广义坐标，可以自动满足约束条件，大大简化了分析。这是分析复杂多体系统、机器人、航天器等问题的重要工具。

自由度 · 系统分析的基础

理力

自由度是确定系统位形所需的独立坐标的个数。对于n个质点，有3n个自由度；对于刚体，有6个自由度（3个平动+3个转动）；对于平面刚体，有3个自由度（2个平动+1个转动）。

自由度是系统分析的基础，决定了需要多少个独立方程来描述系统的运动。约束会减少自由度，每增加一个约束，自由度减少1。这是分析复杂多体系统、机器人、航天器等问题的重要工具。

牛顿第一定律（惯性定律）：如果质点不受力或所受合力为零，则质点保持静止或匀速直线运动状态。这一定律揭示了物体具有保持其运动状态不变的性质，称为惯性。

牛顿第一定律是力学的基础，它定义了惯性参考系的概念。在实际问题中，我们通常选择地面或相对于地面静止或匀速直线运动的参考系作为惯性参考系。这是分析力学问题的基础。

牛顿第三定律 · 作用与反作用

理力

牛顿第三定律（作用与反作用定律）：两个物体之间的作用力F和反作用力F'总是大小相等、方向相反、作用在同一条直线上，即F = -F'。这一定律揭示了力的相互性。

牛顿第三定律是分析物体间相互作用的基础，它说明了力总是成对出现的。在画受力图时，要注意区分作用力和反作用力，它们作用在不同的物体上。这是分析多体系统的基础。

刚体定点转动动力学 · 欧拉动力学方程

理力

刚体定点转动动力学研究刚体绕固定点转动的运动规律。欧拉动力学方程：Ix·dωx/dt + (Iz - Iy)ωyωz = Mx，Iy·dωy/dt + (Ix - Iz)ωzωx = My，Iz·dωz/dt + (Iy - Ix)ωxωy = Mz，其中Ix、Iy、Iz是主转动惯量，ωx、ωy、ωz是角速度在主轴上的分量，Mx、My、Mz是外力矩在主轴上的分量。

欧拉动力学方程是分析刚体定点转动的基础，可以描述刚体在力矩作用下的角加速度。在工程中，欧拉动力学方程广泛应用于陀螺仪、卫星姿态控制、机器人运动学等领域。这是分析刚体定点转动的基础。

进动 · 刚体定点转动的典型现象

理力

进动是刚体定点转动时，自转轴绕空间固定轴（通常是外力矩方向）旋转的现象。进动角速度Ω = M/(I·ω·sinθ)，其中M是外力矩，I是转动惯量，ω是自转角速度，θ是自转轴与外力矩方向的夹角。进动是陀螺运动的典型特征。

进动是刚体定点转动的重要现象，在工程中广泛应用于陀螺仪、导航系统、卫星姿态控制等领域。理解进动现象对于分析刚体定点转动至关重要。这是分析陀螺运动的基础。

章动 · 刚体定点转动的附加运动

理力

章动是刚体定点转动时，自转轴在进动过程中产生的上下摆动现象。章动通常是由于初始条件或扰动引起的，其频率与自转角速度和转动惯量有关。章动角θ的变化满足：d²θ/dt² + (I·ω²/Iz)θ = 0，其中I是横向转动惯量，Iz是纵向转动惯量。

章动是刚体定点转动的附加运动，在工程中需要控制章动以保证系统的稳定性。在陀螺仪、卫星姿态控制等应用中，章动的控制是关键问题。这是分析刚体定点转动的重要概念。

转动主轴 · 刚体转动的简化

理力

转动主轴是刚体绕其转动时，角动量与角速度方向一致的轴。对于刚体，存在三个相互垂直的主轴，称为主转动轴。绕主轴转动时，角动量L = I·ω，其中I是主转动惯量。选择主轴坐标系可以大大简化刚体转动的分析。

转动主轴是分析刚体转动的重要概念，通过选择主轴坐标系可以简化欧拉动力学方程。在工程中，通常选择刚体的对称轴作为主轴，这样可以简化计算。这是分析刚体定点转动的基础。

转动惯量张量 · 刚体转动的完整描述

理力

转动惯量张量I是描述刚体转动惯性的二阶张量，其矩阵形式为：I = [Ixx Ixy Ixz; Iyx Iyy Iyz; Izx Izy Izz]，其中对角元素Ixx、Iyy、Izz是主转动惯量，非对角元素是惯性积。角动量与角速度的关系：L = I·ω。

转动惯量张量是分析刚体转动的完整工具，通过转动惯量张量可以计算任意方向的转动惯量。在工程中，转动惯量张量广泛应用于机器人、卫星、陀螺仪等系统的动力学分析。这是分析刚体定点转动的基础。

冲击力 · 短时间内作用的巨大作用力

理力

冲击力是在极短时间内（Δt → 0）作用的巨大作用力，其冲量I = ∫Fdt是有限值。冲击力的特点是作用时间极短、力值极大，在冲击过程中可以忽略非冲击力（如重力、弹性力等）。冲击力引起的动量变化：Δp = I。

冲击力是分析碰撞、打击、爆炸等问题的重要概念。在冲击过程中，由于作用时间极短，非冲击力（如重力）的冲量可以忽略，只需考虑冲击力的冲量。这是分析碰撞问题的基础。

变质量系统 · 质量随时间变化的系统

理力

变质量系统是质量随时间变化的系统，如火箭、喷气飞机、传送带等。变质量系统的运动方程：m·dv/dt = F + u·dm/dt，其中m是瞬时质量，v是速度，F是外力，u是喷出（或吸入）物质相对于系统的速度，dm/dt是质量变化率。

变质量系统是分析火箭、喷气推进等问题的基础。对于火箭，推力F推 = u·dm/dt，其中u是喷气速度。变质量系统的动量定理需要考虑质量变化对动量的影响。这是分析推进系统的基础。

火箭方程 · 变质量系统的典型应用

理力

火箭方程描述火箭在重力场中的运动。对于垂直发射的火箭，运动方程为：m·dv/dt = -mg - u·dm/dt，其中m是瞬时质量，v是速度，g是重力加速度，u是喷气速度（相对于火箭），dm/dt是质量减少率（负值）。积分得到：v = v0 + u·ln(m0/m) - gt。

火箭方程是变质量系统的重要应用，广泛应用于航天工程。齐奥尔科夫斯基公式v = u·ln(m0/m)给出了理想情况下（无重力、无阻力）火箭的速度增量。这是分析火箭推进的基础。

外力和内力 · 系统分析的基础

理力

外力是系统外物体对系统内物体的作用力，内力是系统内物体之间的相互作用力。根据牛顿第三定律，内力的矢量和为零：ΣF内 = 0。因此，系统的动量变化只取决于外力：dp/dt = F外。这是分析质点系运动的基础。

区分外力和内力是分析质点系运动的关键。内力的冲量和为零，因此不影响系统的总动量。只有外力才能改变系统的总动量。这是动量定理和动量守恒定律的基础。

刚体定轴转动动力学 · 动量矩定理的应用

理力

刚体定轴转动的动力学方程：M = I·α，其中M是合外力矩，I是转动惯量，α是角加速度。这是动量矩定理dL/dt = M在定轴转动中的具体形式，因为L = Iω，所以dL/dt = I·dω/dt = I·α。这是分析定轴转动的基础。

刚体定轴转动动力学方程是分析旋转机械、电机、飞轮等的基础。通过转动方程M = Iα，可以已知力矩求角加速度，或已知角加速度求力矩。这是分析定轴转动问题的基础。

刚体平面运动动力学 · 质心运动与转动的结合

理力

刚体平面运动的动力学方程包括：质心运动定理maC = F（两个分量方程）和绕质心的转动方程IC·α = MC。其中aC是质心加速度，F是合外力，IC是绕质心的转动惯量，α是角加速度，MC是合外力矩。共3个独立方程。

刚体平面运动动力学是分析滚动物体、连杆机构等的基础。平面运动可以分解为随质心的平动和绕质心的转动，分别用质心运动定理和转动方程描述。这是分析平面机构的基础。

质点系动量矩定理 · 系统转动的动力学基础

理力

质点系动量矩定理：dL/dt = M外，其中L = ΣLi是系统的总动量矩，M外 = ΣMi是合外力矩。内力的力矩矢量和为零，因此系统的动量矩变化只取决于外力矩。当M外 = 0时，系统的总动量矩守恒：L = 常数。

质点系动量矩定理是分析转动系统的基础，广泛应用于陀螺、旋转机械、航天器姿态控制等领域。动量矩守恒定律在转动问题中的作用类似于动量守恒定律在平动问题中的作用。这是分析转动系统的基础。

强度理论 · 复杂应力状态的强度判断

材力

强度理论是判断复杂应力状态下材料是否失效的准则。第一强度理论（最大拉应力理论）：σ1 ≤ [σ]；第二强度理论（最大拉应变理论）：σ1 - μ(σ2 + σ3) ≤ [σ]；第三强度理论（最大剪应力理论）：σ1 - σ3 ≤ [σ]；第四强度理论（形状改变比能理论）：√[(σ1-σ2)²+(σ2-σ3)²+(σ3-σ1)²]/2 ≤ [σ]。

强度理论是分析复杂应力状态的基础。第一、二理论适用于脆性材料，第三、四理论适用于塑性材料。第四强度理论（Mises准则）在工程中应用最广泛。这是分析组合变形、压力容器等问题的关键。

截面几何性质 · 材料力学的基础

材力

截面几何性质包括：形心坐标xC = ∫xdA/A，yC = ∫ydA/A；惯性矩Iz = ∫y²dA，Iy = ∫z²dA；极惯性矩Ip = ∫ρ²dA = Iz + Iy；惯性积Iyz = ∫yzdA；抗弯截面系数Wz = Iz/ymax；抗扭截面系数Wp = Ip/R。

截面几何性质是计算应力和变形的基础。平行轴定理：Iz = IzC + Ad²，用于计算平行轴的惯性矩。组合截面的几何性质可以通过各部分几何性质的叠加计算。这是材料力学分析的基础。

梁的挠度计算方法 · 积分法、叠加法、图乘法

材力

计算梁挠度的方法有：1）积分法：通过积分挠曲线微分方程d²w/dx² = M/(EI)得到挠度方程；2）叠加法：利用已知简单荷载的挠度公式，通过叠加得到复杂荷载的挠度；3）图乘法：利用弯矩图的面积和形心位置计算挠度。

积分法适用于任意荷载，但计算较复杂。叠加法适用于线性弹性材料，简单直观。图乘法是能量法的应用，特别适用于等截面梁。在实际工程中，常查表得到常见荷载的挠度公式。这是梁刚度设计的基础。

应变能 · 材料力学的能量概念

材力

应变能U是结构在变形过程中储存的能量。对于线弹性材料：拉压应变能U = N²L/(2EA)；扭转应变能U = Mt²L/(2GIp)；弯曲应变能U = ∫M²dx/(2EI)。总应变能等于各部分的应变能之和。

应变能是能量法的基础。根据功能原理，外力做的功等于应变能：W = U。利用应变能可以计算结构的变形，特别是超静定结构的求解。卡氏定理、单位荷载法都是基于应变能原理。这是能量法的核心概念。

卡氏定理 · 能量法的重要定理

材力

卡氏定理：结构某点的位移等于应变能对该点对应力的偏导数：δi = ∂U/∂Fi。如果要求某点的位移，在该点施加单位力，计算应变能，然后对单位力求偏导。卡氏定理是能量法的重要应用。

卡氏定理特别适用于求解超静定结构。对于超静定结构，可以以多余约束力为未知量，利用卡氏定理建立补充方程。卡氏定理在结构分析、优化设计等领域有广泛应用。这是能量法的重要工具。

单位荷载法 · 计算位移的通用方法

材力

单位荷载法（莫尔积分法）是计算结构位移的通用方法：Δ = ∫(M·M̄)/(EI)dx + ∫(N·N̄)/(EA)dx + ∫(Mt·M̄t)/(GIp)dx，其中M、N、Mt是实际荷载产生的内力，M̄、N̄、M̄t是单位荷载产生的内力。

单位荷载法的步骤：1）计算实际荷载下的内力；2）在所求位移点施加单位荷载，计算单位荷载下的内力；3）代入莫尔积分公式计算位移。单位荷载法适用于任意结构，是结构分析的基础方法。

温度应力 · 热变形引起的应力

材力

温度应力是由于温度变化引起的热变形受到约束而产生的应力。自由热变形：ΔL = α·L·ΔT，其中α是线膨胀系数，ΔT是温度变化。如果热变形受到约束，则产生温度应力：σ = E·α·ΔT。

温度应力在工程中不可忽视，特别是对于超静定结构。温度变化会引起结构变形，如果变形受到约束，就会产生很大的温度应力。在桥梁、管道等结构中，温度应力是重要的设计考虑因素。

力法 · 超静定结构的基本解法

结力

力法是以多余约束力为基本未知量求解超静定结构的方法。力法的基本步骤：1）确定超静定次数，选择基本体系（去掉多余约束）；2）建立力法方程：δ11X1 + δ12X2 + ... + Δ1P = 0；3）计算系数和自由项；4）求解多余约束力；5）叠加得到最终内力。

力法是求解超静定结构的经典方法。力法方程的物理意义是：基本体系在多余约束力Xi和荷载共同作用下，多余约束处的位移为零（变形协调条件）。力法适用于各种超静定结构，是结构力学的基础方法。

位移法 · 以节点位移为未知量

结力

位移法是以节点位移（转角和线位移）为基本未知量求解超静定结构的方法。位移法的基本步骤：1）确定基本未知量（节点位移）；2）建立位移法方程：k11Δ1 + k12Δ2 + ... + F1P = 0；3）计算刚度系数和荷载项；4）求解节点位移；5）计算杆端内力。

位移法特别适用于刚架、连续梁等结构。位移法的优点是方程数量少，计算效率高。位移法方程的物理意义是：节点处的平衡条件。位移法是现代结构分析的基础，矩阵位移法就是位移法的矩阵形式。

力矩分配法 · 无侧移刚架的实用方法

结力

力矩分配法是一种渐近法，通过逐次分配和传递节点不平衡力矩来求解无侧移刚架。基本步骤：1）计算各杆的转动刚度S和分配系数μ；2）固定节点，计算固端弯矩；3）放松节点，分配不平衡力矩；4）传递弯矩到远端；5）重复步骤3-4直到收敛。

力矩分配法特别适用于无侧移刚架和连续梁。力矩分配法的优点是计算过程直观，不需要解方程组。分配系数μ = S/ΣS，传递系数C = 1/2（远端固定）或C = 0（远端铰支）。这是结构分析的实用方法。

矩阵位移法 · 结构分析的现代方法

结力

矩阵位移法是位移法的矩阵形式，适用于计算机求解。基本步骤：1）建立单元刚度矩阵[k]；2）组装整体刚度矩阵[K]；3）建立荷载向量{F}；4）求解位移方程[K]{Δ} = {F}；5）计算单元内力。矩阵位移法是现代结构分析软件的基础。

矩阵位移法的优点是适用于任意复杂结构，计算效率高，易于编程实现。整体刚度矩阵[K]由各单元刚度矩阵按节点编号组装而成。矩阵位移法是有限元法的基础，广泛应用于工程结构分析。

变形协调方程 · 超静定结构的补充条件

结力

变形协调方程是超静定结构求解的补充条件，表示结构在多余约束处的位移必须满足几何约束条件。对于力法，变形协调方程是：基本体系在多余约束处的位移为零。对于位移法，变形协调方程隐含在节点位移的定义中。

变形协调方程是超静定结构与静定结构的根本区别。静定结构只需平衡方程即可求解，超静定结构需要平衡方程和变形协调方程共同求解。变形协调方程保证了结构的几何连续性和完整性。

结构的塑性分析 · 极限荷载

结力

结构的塑性分析是研究结构在塑性阶段的承载能力。当结构某截面达到塑性极限弯矩Mp时，该截面形成塑性铰。当结构形成足够多的塑性铰时，结构变为机构，此时的荷载就是极限荷载Pu。极限荷载大于弹性极限荷载。

塑性分析考虑了材料的塑性性能，可以更充分地利用材料的承载能力。塑性分析的方法有：机构法（寻找可能的破坏机构）、平衡法（建立平衡方程）。塑性分析在结构设计中有重要应用，可以提高结构的经济性。
