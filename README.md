# 三力学 AI 可视化学习工具
注意：接入api方法下方有讲，同时理论力学篇机械振动基础往后的章节模型有错误
一个集成了理论力学、结构力学和材料力学的交互式可视化学习平台，支持 2D/3D 模型展示、参数调整、习题生成和 AI 自动解答功能。

- **DeepSeek AI 解答**：一键获取 AI 生成的详细解答

## 🚀 快速开始

### 环境要求
- 现代浏览器（Chrome、Firefox、Edge 等）
- 无需安装，直接打开 `index.html` 即可使用

### 配置 DeepSeek API（可选）

如需使用 AI 自动解答功能，需要配置 DeepSeek API Key：

1. 获取 API Key：
   - 访问 [DeepSeek 平台](https://platform.deepseek.com/)
   - 注册账号并获取 API Key

2. 配置 API Key：
   - 打开 `main.js` 文件
   - 在文件顶部找到配置区域：
   ```javascript
   const DEEPSEEK_CONFIG = {
     API_KEY: "", // 请在此处填入您的 DeepSeek API Key
     API_URL: "https://api.deepseek.com/v1/chat/completions",
     MODEL: "deepseek-chat",
     MAX_TOKENS: 2000,
     TEMPERATURE: 0.7
   };
   ```
   - 将您的 API Key 填入 `API_KEY` 字段

3. 使用 AI 解答：
   - 生成习题后，点击"让 DeepSeek 解答"按钮
   - 等待 AI 生成详细解答

## 📖 使用指南

### 基本操作

1. **选择学科**：点击顶部导航栏选择"理论力学"、"结构力学"或"材料力学"
2. **选择模型**：在右侧模型库中选择要学习的模型
3. **调整参数**：在参数区域修改物理参数，观察模型变化
4. **切换视图**：点击"2D 模式"或"3D 模式"切换视图
5. **生成习题**：点击"生成习题"按钮，根据当前参数生成题目
6. **AI 解答**：点击"让 DeepSeek 解答"获取详细解答

### 可视化交互

- **拖动元素**：部分模型支持拖动交互（如门板、扳手等）
- **实时更新**：参数修改后，模型和 HUD 数据实时更新
- **动画演示**：自动播放运动过程、受力变化等动画

### 习题功能

- **参数化生成**：根据当前模型参数自动生成对应题目
- **多模型支持**：不同模型生成不同类型的题目
- **AI 解答**：一键获取分步骤详细解答

## 🔧 自定义配置

### 修改 API 配置

在 `main.js` 顶部可以修改：
- `API_KEY`：DeepSeek API 密钥
- `API_URL`：API 接口地址（如使用代理）
- `MODEL`：使用的模型名称
- `MAX_TOKENS`：最大生成 token 数
- `TEMPERATURE`：生成温度（0-1，越高越随机）

### 添加新模型

1. 在 `index.html` 中添加 SVG 场景
2. 在 `main.js` 中添加模型配置
3. 添加对应的动画函数
4. 更新模型映射关系

## 📝 注意事项

1. **API Key 安全**：请勿将包含真实 API Key 的代码上传到公开仓库
2. **网络连接**：使用 AI 解答功能需要网络连接
3. **浏览器兼容**：建议使用最新版本的现代浏览器
4. **性能优化**：部分复杂模型可能影响性能，建议关闭不必要的动画
