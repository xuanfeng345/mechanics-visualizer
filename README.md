# 力学学习实验室

保留原有模型库与知识卡，在此基础上增量扩展理论力学和材料力学操练场。**当前包含12个课程包、128关、17个自由实验场景；原静力学20关保留。**

本次升级围绕学习闭环：概念预测 → 建模判断 → 写下思路并独立作答 → 本章变式 → 到期复习。首页直接进入新版学习平台，旧知识库仅通过明确的入口手动访问。

> 本工具用于观察、练习与教学辅助，不替代教材、教师、真实实验、考试训练、工程设计或设计规范。“独立完成”仅表示一次未使用内置提示的答题表现，不等于长期掌握。

## A 版统一界面

[playground.html](playground.html) 默认使用浅色精密仪器台，覆盖全部 12 个课程的公共界面。顶部常驻“理论力学 / 材料力学”与对应六门课程；选择学科仅浏览课程列表，点击课程才进入学习，完成记录保留。手机端可横向滑动课程，选中项自动进入可见区域。

[precision.html](precision.html) 是振动自由实验快捷入口。运动学、质点动力学、刚体动力学、振动和拉格朗日谐振子均支持按观察时间播放、暂停、单步与慢放；振动另支持曲线定位；其他场景沿用原有模型绘图。可通过 [经典界面](playground.html?ui=classic) 返回原布局。设计与验证范围见 [PRECISION_DESIGN.md](PRECISION_DESIGN.md)。隔离浏览器启动后可用 `npm run test:precision` 验收。

## 版本下载

在 [GitHub Releases](https://github.com/xuanfeng345/mechanics-visualizer/releases/latest) 下载 `mechanics-visualizer-v0.2.0.zip`，完整解压后打开 `index.html`。该压缩包包含本地公式资源，保留目录结构即可使用。

## 快速开始

1. 下载本仓库并完整解压，保留文件夹结构。
2. 用现代浏览器打开 [index.html](index.html)，直接进入新版学习平台；[playground.html](playground.html) 也是相同入口，无需安装依赖或启动服务器。
3. [knowledge.html](knowledge.html) 是保留的旧模型库与知识卡入口，只有手动打开才会进入。旧模型仍有待完善项目，不代表每个模型均已全面验证。
4. 更新前先在操练场导出 JSON 进度备份。更新后如仍显示旧页面，可重新打开或强制刷新。

操练场使用本地 MathJax，核心练习无需 AI API。旧入口的外部公式资源、可选 AI 功能需要网络。当前没有可用的逐模型3D求解器，3D入口处于禁用状态。

## 新学习平台

**图解公式已覆盖全部 17 个实验场景**，保留原有步骤按钮、大公式、文字解释与图形高亮；扩展场景读数也使用 MathJax 排版。运动学按抛体、圆周与平移参考系切换公式，振动按阻尼类型切换响应，并严格区分角频率 rad/s 与频率 Hz。


- **学习中心**提供继续学习、待复习、错题与待巩固、课程路线及最近作答。原题独立完成、本章变式独立完成和延迟复习通过分开计数，不宣称永久掌握。
- **全课程概念与建模检查**先作答再揭示解释；选择式检查不等于自由绘制受力图。关卡仍按题目给定条件作答，场景初值不一定与理论题相同。
- **独立作答**保留直接展示的 MathJax 公式与分步图解，可先写研究对象、列式和单位检查。思路随作答保存，系统不自动判定自由文本推导的正确性。主动使用提示，或本次尝试中答错后重试，均作为辅助证据；正常浏览公式不计为使用提示。重新进入关卡可开始独立尝试。刷新不会清除本次辅助标记。
- **精度与反馈**按题目数值大小收紧允许误差，避免 0.00625 rad 的题目被 0 答案通过；对可能的符号、单位和数量级错误提供检查方向。错误类型提示是启发式判断，不替代推导审阅。
- **本章变式与间隔复习**保留原 12 类章节参数模板，并为新增材料关卡提供 7 类对应专题模板，各模板有 7 组参数；不是每道原题各自独立的一套变式。原题独立完成后 1 天、本章变式独立完成后 3 天到期；延迟复习通过后间隔 7、14、30 天。同日练习不会冒充延迟复习；提示后完成不算独立通过。到期提示仅在打开页面时显示，不发送外部通知。
- **实验台**补齐刚体、振动、拉格朗日参数，提供运动学类型、质点二维力和初速度、全部数值控件的精确输入、梁长与载荷位置联动，以及条件和响应的 A/B 对比。A/B 快照仅在当前页面保留，不属于进度备份。
- **释放实验**使用当前坡角、静摩擦系数与支座条件。动摩擦系数显式设置且不超过静摩擦系数；杆件可保留或撤去外力，保留时方向相对地面固定。支持无支座杆、暂停、0.25 倍慢放、0.02 s 单步、最近速度曲线、杆件能量和动态反力。改变实验参数会结束当前释放并恢复静态视图。观察边界只暂停，不计算碰撞。
- **存档兼容**沿用 schema 4 与原 localStorage 键。增加学习事件和本次尝试状态，随 JSON 备份导入导出；旧完成记录保留，不倒推为新独立/变式/延迟证据。最多保留最近 1500 条事件，超出后较早的学习证据可能不再计入学习中心汇总。

## 梁的联动分析

在材料力学 → 梁弯曲中，实验台可切换两端简支 / 左端固定悬臂、集中载荷 / 全跨均布载荷。集中载荷使用 P（N），均布载荷使用 q（N/m），两种数值独立保留。切换模型后，反力、剪力图、弯矩图、挠曲线和分步公式同步更新。

拖动图中的截面线或用方向键、Home / End，可读同一截面的 V、M、v 和下缘弯曲正应力；集中载荷处分别给出左右剪力。曲线独立缩放，挠度向下为正；短桌面三图并排，长桌面上下对齐。原有 108 关与存档保留；材料力学扩展另增加 20 个关卡。

只适用于线弹性、等 EI、Euler–Bernoulli 小挠度梁，不包含剪切变形、塑性、任意多载荷或超静定求解。计算依据与验证见 [BEAM_ANALYSIS.md](BEAM_ANALYSIS.md)，浏览器验收命令为 `npm run test:beam`。

## 材料力学补充内容

- **梁弯曲**：保留四种梁工况；增加矩形、实心圆、圆环、对称工字形的面积、惯性矩、中性轴及应力分布，以及 VQ/(Ib) 横向剪应力。可拖动截面高度，同时读正应力与剪应力。
- **组合应力**：从矩形悬臂端力与轴力出发求拉弯危险点，或计算实心圆轴外缘的弯扭组合、面内主应力和 von Mises 静载屈服利用率。拉弯计入矩形横向剪应力；弯扭外缘模型不含横向剪切。
- **轴向杆**：自由热变形、完全/部分约束热应力；两端固定、两段等 E 不同长度和面积的结点受力，联立平衡与变形协调求反力、内力和位移。
- 新增 20 关按专题进入原判分、思路记录、学习证据、变式及间隔复习，原题 ID 与完成记录保留。原课程末尾存档迁移时，不会把新增第一关当成已经通过。

可从课程地图进入对应新增单元；自由模式选择“材料综合实验”可切换全部六个实验主题。数学依据、假设和验收见 [MATERIALS_EXTENSION.md](MATERIALS_EXTENSION.md)，运行 `npm run test:materials` 检查新增浏览器交互。

## 课程与学习方式

| 地图 | 建议路线 |
| --- | --- |
| 理论力学 | 静力学 → 运动学 → 质点动力学 → 刚体动力学 → 振动 → 拉格朗日分析力学 |
| 材料力学 | 轴向杆 → 圆轴扭转 → 梁弯曲 → 组合应力 → Euler屈曲 → 疲劳 |

- 静力学20关分为力矩与力臂、约束与受力图、平衡方程、静摩擦、综合迁移5个单元。
- 教学流程包含观察或操作、独立答题、反馈与解析；题目给定条件可能不同于实验初值，应以题目为准。
- 四级提示依次为方向、方法、关键步骤、完整讲解；辅助完成与独立完成分别记录。
- 答案输入支持小数、简单分数和科学计数法，例如 `40/3`、`2e11`。按题目单位输入，不附加单位，不执行表达式或脚本。实验参数精确输入支持小数与科学计数法。
- 格式错误单独提示，不计入答错次数。
- 章节回顾显示已练习、独立完成和待独立练习数量，可进入首个尚未独立完成的关卡；学习中心另提供章节参数变式和到期复习。
- 自由模式提供17个场景，供调整参数、观察 SVG 和读数；不是任意结构搭建或完整工程仿真。

建议将页面练习与纸笔推导、陌生题迁移、量纲检查及延迟复习结合，不以通关数判断学习效果。

## 进度与备份

- 进度默认保存在当前浏览器的 localStorage，键为 `mechanics-playground-v3`，当前状态结构为 schema 4。
- 12个课程分别保存完成记录。切课不会清空已有完成记录，但会重置本次尝试的提示、错误计数等状态。
- 页面提供 JSON 导出和导入，支持 schema 3/4 校验与迁移。损坏或不支持的数据会拒绝导入，不修改当前进度。
- 保存失败会持续显示警告；导入仅恢复到内存时，也会明确提醒关闭或刷新可能丢失。
- 本地文件位置、浏览器配置或存储策略变化可能影响恢复，请保留外部备份；不要依赖浏览器缓存作为唯一副本。

- [js/engine-browser.js](<js/engine-browser.js>)、[js/release-view.js](<js/release-view.js>)：浏览器释放计算与动画。
- [js/lesson-math.js](<js/lesson-math.js>)、[js/formula-guide.js](<js/formula-guide.js>)：动态公式排版与图解。

## 模型适用范围与待完善内容

- 静摩擦按需求取值且不超过上限，不总等于 μN；未指定动摩擦模型时不计算滑动摩擦运动。
- 梁采用 Euler–Bernoulli 小挠度等理想化假设；圆轴扭转为线弹性 Saint-Venant 模型；Euler屈曲适用于理想细长弹性柱。
- 疲劳采用简化 Basquin/Goodman 模型，不覆盖完整载荷谱、裂纹扩展和工程规范设计。
- 杆件释放采用半隐式 Euler 并逐步更新力矩；斜面在恒加速度段解析步进并处理停止后的静摩擦切换。部分阻尼/受迫振动内核采用 RK4，不宣称完整工程精确解。
- 单位以各题和场景标注为准；轴向杆采用 N–mm–MPa，其他模型常用 SI，不可默默混用面积、惯性矩或应力单位。
- 完整碰撞、复杂刚体约束、多自由度/非线性振动、塑性、断裂及结构力学体系仍待扩展。
- 旧模型库仍存在参数、示意图和动画生命周期等待逐项复核内容，不能将目录中的模型名称当作已验证能力清单。
