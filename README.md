# 三力学可视化学习工具

保留原有模型库与知识卡，在此基础上增量扩展理论力学和材料力学操练场。**当前包含12个课程包、108关、16个自由实验场景；原静力学20关保留。**

> 本工具用于观察、练习与教学辅助，不替代教材、教师、真实实验、考试训练、工程设计或设计规范。“独立完成”仅表示一次未使用内置提示的答题表现，不等于长期掌握。

## 快速开始

1. 下载本仓库并完整解压，保留文件夹结构。
2. 推荐直接用现代浏览器打开 [playground.html](<playground.html>)，进入课程操练场，无需安装依赖或启动服务器。
3. [index.html](<index.html>) 是保留的旧模型库与知识卡入口。旧模型仍有待完善项目，不代表每个模型均已全面验证。
4. 更新前先在操练场导出 JSON 进度备份。更新后如仍显示旧页面，可重新打开或强制刷新。

操练场使用本地 MathJax，核心练习无需 AI API。旧入口的外部公式资源、可选 AI 功能需要网络。当前没有可用的逐模型3D求解器，3D入口处于禁用状态。

## 课程与学习方式

| 地图 | 建议路线 |
| --- | --- |
| 理论力学 | 静力学 → 运动学 → 质点动力学 → 刚体动力学 → 振动 → 拉格朗日分析力学 |
| 材料力学 | 轴向杆 → 圆轴扭转 → 梁弯曲 → 组合应力 → Euler屈曲 → 疲劳 |

- 静力学20关分为力矩与力臂、约束与受力图、平衡方程、静摩擦、综合迁移5个单元。
- 教学流程包含观察或操作、独立答题、反馈与解析；题目给定条件可能不同于实验初值，应以题目为准。
- 四级提示依次为方向、方法、关键步骤、完整讲解；辅助完成与独立完成分别记录。
- 数值输入支持小数、简单分数和科学计数法，例如 `40/3`、`2e11`。按题目单位输入，不附加单位，不执行表达式或脚本。
- 格式错误单独提示，不计入答错次数。
- 章节回顾显示已练习、独立完成和待独立练习数量，可进入首个尚未独立完成的关卡；目前是原题复习，不是变式或延迟测验。
- 自由模式提供16个场景，供调整参数、观察 SVG 和读数；不是任意结构搭建或完整工程仿真。

建议将页面练习与纸笔推导、陌生题迁移、量纲检查及延迟复习结合，不以通关数判断学习效果。

## 进度与备份

- 进度默认保存在当前浏览器的 localStorage，键为 `mechanics-playground-v3`，当前状态结构为 schema 4。
- 12个课程分别保存完成记录。切课不会清空已有完成记录，但会重置本次尝试的提示、错误计数等状态。
- 页面提供 JSON 导出和导入，支持 schema 3/4 校验与迁移。损坏或不支持的数据会拒绝导入，不修改当前进度。
- 保存失败会持续显示警告；导入仅恢复到内存时，也会明确提醒关闭或刷新可能丢失。
- 本地文件位置、浏览器配置或存储策略变化可能影响恢复，请保留外部备份；不要依赖浏览器缓存作为唯一副本。

### 代码分层

- [js/playground.js](<js/playground.js>)：课程地图、答题、提示、场景适配、进度迁移和备份。
- [js/main.js](<js/main.js>)：旧入口逻辑，保留可选 DeepSeek 配置。不要提交包含真实 API Key 的代码；客户端配置不适合存放共享密钥。AI答案不作为物理校验依据。
- 课程数据位于 `js/*-curriculum.js`，另有 [js/curriculum.js](<js/curriculum.js>) 的原静力学课程；均提供 `{units, levels}`，支持浏览器与 CommonJS 加载。
- 场景模块位于 `js/*-scene.js`，输出 SVG 和物理读数；[js/statics-scenes.js](<js/statics-scenes.js>) 提供静力场景。
- [engine/index.js](<engine/index.js>)：汇总单位、向量、静力、动力学、约束、积分、诊断和材料专项内核。
- [js/engine-browser.js](<js/engine-browser.js>)、[js/release-view.js](<js/release-view.js>)：浏览器释放计算与动画。
- [js/lesson-math.js](<js/lesson-math.js>)、[js/formula-guide.js](<js/formula-guide.js>)：动态公式排版与图解。

### 扩展约定

保留稳定的关卡 ID 和已有进度语义；题设、答案、单位、模型假设、四级提示应一起核验。场景初值不等于独立题目题设。LaTeX只用于显示，JavaScript字符串中的反斜杠需正确转义。

修改课程或模型时，补充边界、零值、非有限值、解析对照与回归测试；更新资源位置时同步更新 HTML、测试和文档路径。所有文本使用 UTF-8。旧文档中的完整 JSON Schema、符号判题、尝试日志和延迟评估属于设计设想，不是当前已经实现的运行契约。

## 开发与验证

建议使用 Node.js 22 或更新版本（浏览器脚本使用原生 WebSocket），基础测试无需额外 npm 依赖。

```bash
npm test
npm run check
npm run test:kernel
```

真实浏览器测试需要先启动**隔离配置**的 Edge/Chromium，不要连接个人浏览器：

```powershell
& 'C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe' `
  --headless=new --disable-gpu --no-first-run `
  --remote-debugging-port=19422 `
  --user-data-dir="$env:TEMP\mechanics-browser-test" about:blank
npm run test:browser
node tests/browser-encoding.cjs
```

最后一条检查两个页面的中文文本，并关闭该调试浏览器；浏览器安装路径可按本机调整。

## 模型适用范围与待完善内容

- 静摩擦按需求取值且不超过上限，不总等于 μN；未指定动摩擦模型时不计算滑动摩擦运动。
- 梁采用 Euler–Bernoulli 小挠度等理想化假设；圆轴扭转为线弹性 Saint-Venant 模型；Euler屈曲适用于理想细长弹性柱。
- 疲劳采用简化 Basquin/Goodman 模型，不覆盖完整载荷谱、裂纹扩展和工程规范设计。
- 释放动画采用半隐式 Euler；部分阻尼/受迫振动计算采用 RK4，不宣称解析精确解。
- 单位以各题和场景标注为准；轴向杆采用 N–mm–MPa，其他模型常用 SI，不可默默混用面积、惯性矩或应力单位。
- 完整碰撞、复杂刚体约束、多自由度/非线性振动、塑性、断裂及结构力学体系仍待扩展。
- 旧模型库仍存在参数、示意图和动画生命周期等待逐项复核内容，不能将目录中的模型名称当作已验证能力清单。
